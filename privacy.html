Как обрабатываются данные

Tendermost — приложение владельца для организации его собственного рабочего процесса с документацией закупок.

Какие данные использует приложение

  • Идентификатор Google-аккаунта и техническое разрешение OAuth для выполнения согласованных действий.
  • Ссылки, названия и идентификаторы закупок, переданные владельцем, а также служебные данные запросов.
  • Документы закупок, результаты проверки файлов, сведения о ходе обработки и подтверждения завершения анализа.
  • Сохранённое состояние входа в Контур.Закупки, необходимое для получения доступных владельцу документов.

Пароль Google не вводится в Tendermost: авторизация проходит на стороне Google. Область разрешений Google — https://www.googleapis.com/auth/drive.file.

Зачем нужны эти данные

Данные используются для чтения очереди, получения документации, проверки файлов, загрузки временного пакета на Диск владельца, ведения состояния обработки и проверки условий очистки.

Приложение не использует полученные данные для рекламы, продажи данных или построения рекламных профилей.

Где хранятся данные и кто имеет доступ

Рабочее состояние, журнал и временные документы сохраняются на компьютере, где владелец запустил программу. Данные авторизации защищаются средствами Windows и привязываются к учётной записи пользователя.

Облачные пакеты, служебные таблицы и итоговые отчёты находятся в Google Drive владельца. Доступ определяется его настройками Google Drive и подключённых сервисов. Программа сама не включает общий доступ по ссылке.

Настроенные владельцем задачи ChatGPT могут получать документы через его подключение к Google Drive и отправлять сформированный отчёт указанным им получателям через Gmail. Эти подключения и получатели управляются владельцем отдельно. У EXE нет собственного разрешения Gmail для чтения или отправки почты.

Срок хранения и удаление

До завершения обработки файлы сохраняются для продолжения работы после прерывания. Если владелец включил очистку, программа окончательно удаляет свой временный пакет после проверки подтверждения анализа, итогового отчёта и отправки. Постоянный итоговый отчёт и журнал остаются.

Владелец может остановить программу, самостоятельно удалить свои файлы на компьютере или Диске и отозвать доступ приложения в настройках Google-аккаунта. Отзыв доступа не удаляет ранее созданные файлы автоматически.

Использование данных Google

Использование и передача данных, полученных через Google API, должны соответствовать Google API Services User Data Policy, включая требования Limited Use. Данные используются только для описанного рабочего процесса владельца и не используются приложением для обучения общих моделей ИИ. Работа отдельно подключённых сервисов регулируется их условиями и настройками владельца.

Этот информационный сайт

На страницах нет формы загрузки документов, входа в Google, рекламных блоков или добавленной нами веб-аналитики. При размещении на GitHub Pages технические данные посещения обрабатываются GitHub согласно политике конфиденциальности GitHub.

Контакт и изменения

Вопросы об обработке данных и удалении направляйте владельцу приложения: ramgpt.rss@gmail.com. При изменении работы программы это описание обновляется с указанием новой даты.
